## 📈 Model Evaluation

Machine learning models are evaluated using different performance metrics, including:

* Accuracy
* Precision
* Recall
* F1 Score
* Confusion Matrix
* Cross Validation

Example:

```python
from sklearn.metrics import accuracy_score, f1_score

accuracy = accuracy_score(y_test, y_pred)
f1 = f1_score(y_test, y_pred)

print("Accuracy:", accuracy)
print("F1 Score:", f1)
```
