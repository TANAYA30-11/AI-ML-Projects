# ❤️ Heart Disease Prediction

## Project Overview
This project uses Machine Learning to predict the possibility of heart disease based on patient health-related features.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab
- Jupyter Notebook

## Machine Learning
The project includes data preprocessing, exploratory data analysis, model training, and model evaluation.

## Dataset
The model is trained using a heart disease dataset containing various patient health features.
